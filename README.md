🎬 YouTube Clone

A fully responsive YouTube Clone built using HTML, CSS And JavaScript. This project replicates core features of YouTube like video browsing, search, and playback with a clean and user-friendly interface.

🚀 Features:<br>
🔍 Search videos<br>
🎥 Video player with controls<br>
📂 Categories / Sidebar navigation<br>
🧾 Video details (title, views, channel info)<br>
👍 Like / Subscribe UI (static or dynamic)<br>
📱 Fully Responsive (Mobile + Desktop)<br>
⚡ Fast loading UI

🛠️ Tech Stack:<br>
Frontend: HTML5, CSS3, JavaScript<br>
Styling: CSS / Tailwind CSS

⚙️ Installation & Setup:<br>
1. Clone the repository:
git clone https://github.com/your-username/youtube-clone.git
2. Navigate to the project:
cd youtube-clone
3. Run the project:
For HTML/CSS/JS version:
Open index.html in browser
OR
Use Live Server (VS Code)
For React version:

npm install
npm start

🔑 API Setup (Optional)<br>
If using YouTube API:<br>
Go to Google Cloud Console<br>
Create a new project<br>
Enable YouTube Data API v3<br>
Generate API Key<br>
Add it in your project:<br>
const API_KEY = "YOUR_API_KEY";
